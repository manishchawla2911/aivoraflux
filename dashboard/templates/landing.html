The studio

Two ways to craft. One way to ship.

🛠

Manual builder

Write the system prompt yourself, pick the model, attach tools, set temperature, choose a guardrail profile. Every knob exposed.

  • — Live token & cost estimate per provider
  • — Versioned prompts with diff view
  • — 12 plug-and-play tools out of the box

Auto-craft

Describe what you want in one sentence. We synthesize the prompt, pick the right tools, recommend guardrails, and you can run it instantly.

  • — Powered by Claude Sonnet 4.6 by default
  • — Editable after generation — nothing is locked
  • — Cold-start fallback if no API key is configured
