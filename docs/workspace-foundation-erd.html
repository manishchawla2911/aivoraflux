Relationships

  • Workspace  →  WorkspaceMember  (a workspace has many members)
  • Workspace  →  WorkspaceMemory  (a workspace has many memory entries)
  • WorkspaceMember  →  Agent  (each member is one reused Agent — option C)
  • Agent  →  GuardrailProfile  (existing link — members are guardrailed for free)
  • WorkspaceMemory.id  =  ChromaDB document id  (SQLite = truth, Chroma = semantic index)
  • owner_email matched by string across Workspace / Agent (no FK, mirrors existing code)
